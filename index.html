ロック

17時になったら、スマホはもうお子ちゃまのものじゃない。勉強するか、寝るか。以上。

なにこれ

iPhone に構成プロファイルを入れて、17時以降のスマホをただの光る板に近づけるサイトです。プロファイルはこの場で生成されます。サーバーは通りません。

あわせて、ホーム画面に「お子ちゃま」アイコンを置きます。開くと全画面で「お子ちゃまはもうスマホをやめて勉強するか寝ましょう」と出ます。

プロファイルをつくる


  


  

    
手順

    
    
      
  1. iPhone の Safari でこのページを開くChrome だとインストール画面が出ないことがあります。
    2. 
      
  2. 上のボタンでプロファイルを落とす「構成プロファイルがダウンロードされました」と出ます。
    3. 
      
  3. 設定 → 一般 → VPN とデバイス管理ダウンロード済みをタップ →「インストール」→ パスコード。
    4. 
      
  4. 設定 → スクリーンタイム → ダウンタイムここが本命です。17:00 〜 翌 7:00 に設定。「ダウンタイム中は常に許可」は電話だけに。
    5. 
      
  5. 設定 → スクリーンタイム → コンテンツとプライバシーの制限「アカウント変更」をオフ。これでダウンタイムを自分で解除できなくなります。パスコードは親が握る。
    6. 
    

  


  

    
先に言っておく穴

    
    
      
  • プロファイル単体では時間で止まりません。iOS の構成プロファイルに「17時に発動」という項目が存在しないためです。時間で自動的に止めるのはダウンタイムの役割で、プロファイルはその抜け穴（Safari・App Store・Siri）を塞ぐ係です。両方セットで使ってください。
    • 
      
  • 設定アプリは消せません。ダウンタイム中でも開けます。スクリーンタイムのパスコードを別の4桁にして本人に知らせないのが実質的な鍵です。
    • 
      
  • プロファイルは手動で消せます。「アカウント変更」をオフにしておくと、消すのにスクリーンタイムのパスコードが要ります。
    • 
      
  • 17時より前に始めた動画は止まりません。ダウンタイムはアプリの起動を止める仕組みで、再生中のストリームは切れません。
    • 
      
  • プロファイルを消されると元に戻ります。再起動では維持されます。
    •
